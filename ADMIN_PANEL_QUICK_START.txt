📊 **پنل مدیریت فراز برتر رامونا - راهنمای سریع**

═══════════════════════════════════════════════════════════════════════════════

🎯 **دسترسی سریع:**
   • URL: http://localhost:3000/admin
   • دکمه "بازگشت به سایت" در هدر برای بازگشت سریع

═══════════════════════════════════════════════════════════════════════════════

📋 **بخش‌های اصلی (8 بخش):**

   1. 📊 داشبورد
      └─ مشاهده کلی آمار و نمودارهای فروش

   2. 💬 درخواست‌های مشاوره
      └─ مدیریت درخواست‌ها (تایید/رد/حذف)

   3. 📚 مدیریت دوره‌ها
      └─ افزودن/ویرایش/حذف دوره‌های آموزشی

   4. 👥 مدیریت کاربران
      └─ مشاهده و حذف حساب‌های کاربری

   5. 🏢 مدیریت پروژه‌ها
      └─ مدیریت پروژه‌های راه‌اندازی

   6. 👨‍💼 مدیریت تیم
      └─ افزودن/ویرایش/حذف اعضای تیم

   7. 💳 مدیریت پرداخت‌ها
      └─ مراقبت تراکنش‌ها و وضعیت پرداخت

   8. 📈 گزارشات و آمار
      └─ آمار جامع و نمودارهای درآمد

═══════════════════════════════════════════════════════════════════════════════

🌐 **مدیریت محتوای وبسایت (4 بخش):**

   ├─ صفحه خانه
   │  └─ تغییر عنوان، متن بنر، و تصویر
   │
   ├─ درباره ما
   │  └─ ویرایش اطلاعات بخش درباره
   │
   ├─ مدیریت محتوا
   │  └─ نمایش/مخفی کردن بخش‌های مختلف
   │
   └─ تنظیمات سایت
      └─ نام سایت، اطلاعات تماس، شبکه‌های اجتماعی

═══════════════════════════════════════════════════════════════════════════════

✨ **ویژگی‌های برجسته:**

   ✅ طراحی کامل ریسپانسیو (موبایل/تبلت/دسکتاپ)
   ✅ رابط کاربری بدیهی و حرفه‌ای
   ✅ منوی جانبی تاشو برای موبایل
   ✅ دکمه بازگشت سریع به وبسایت
   ✅ نمودارهای پویا و آمار لحظه‌ای
   ✅ رنگ‌های هماهنگ با برند (طلایی و تیره)
   ✅ پیام‌های موفقیت و خطا
   ✅ ذخیره‌سازی در localStorage

🔧 **راهنمای تغییرات:**

   1️⃣ برای ویرایش متن سایت:
      → صفحه خانه / درباره ما / مدیریت محتوا

   2️⃣ برای افزودن دوره جدید:
      → مدیریت دوره‌ها → دکمه "دوره جدید"

   3️⃣ برای مدیریت درخواست‌های مشاوره:
      → درخواست‌های مشاوره → عملیات (تایید/رد/حذف)

   4️⃣ برای تغییر تنظیمات سایت:
      → تنظیمات سایت → تغییر اطلاعات → ذخیره
